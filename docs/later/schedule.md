# 33 钟不知道要问模型

> 这一课只认一件事：定时器只负责到点调用一个函数。函数里要不要走课 21 的循环，由注册的人决定。

## 问题

「每天早上让 agent 看一遍邮件」如果写进调度器，调度器就会依赖提示词、模型和数据库。换一种定时任务，就要改钟。

## 最小做法

钟只有时间。回调是别人的。

```ts
schedule({
  cron: '0 8 * * *',
  run() {
    return startChat({ text: '总结昨晚的邮件' })
  }
})
```

`startChat` 就是课 03 那条路：调度台、循环、工具。钟不保存邮件，也不知道 `startChat` 里面有模型。它提供登记、暂停、取消和「下次几点响」。

界面上的定时结果卡片，是这一轮运行写进消息的工具块，仍由课 09 按名字画。卡片里没有 cron 表达式。

## 在 Cherry Studio 里

钟在 `src/main/core/scheduler`，方法是 `registerSchedule`、暂停、恢复、取消。到点之后跑 agent 的产品代码在登记回调的那一侧。

## 整门课

从输入框到气泡，中间是一次流式调用、一组插件，和一个「有工具就继续」的循环。外部 agent 不重复这个循环，只把事件收成同样的块。之后你打开任何一个文件，先问它在加哪一件事：画、过桥、调用、循环，还是观察别人的循环。对得上，文件名就不再挡路。
