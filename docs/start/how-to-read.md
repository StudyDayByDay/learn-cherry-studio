# 怎么读这份导航

预计 10 分钟。

## 这一坐要看懂什么

这份站点和 Cherry Studio 仓库是分开的。站点只做导航，代码仍以 `agent/cherry-studio` 为准。摘录是写导航时从那个仓库抄出来的短片段，行号以后可能移动，路径不会轻易改。

课按你的背景排列：先看 React 界面，再看 Electron 的进程边界，再看 Vercel AI SDK 和 agent。每一课五段：要看懂什么、先打开哪个文件、关键代码、记住这一点、先不要展开的目录。

## 先打开哪个文件

先不要打开 Cherry Studio。先把侧边栏从上到下扫一眼，确认自己停在哪一课。

## 关键代码

没有。这一课约定读法：

- 源文件路径都相对 `agent/cherry-studio/`。
- 代码块只保留能说明职责的几行。
- 看到「先不要展开」就停。那些目录是产品细节，主线用得到时再回来。

## 记住这一点

一次只跟一条链：用户打字，模型回话，界面把字画出来。跑偏到语音、打包、数据库时，回到 [一条消息的全程](/map/one-message)。

## 先不要展开的目录

- `src/main/ai` 整棵树，大约一千多个文件。后面的课会点名其中几个入口。
- `native/`、`scripts/`、`docs/website/`。它们是安装、打包和产品文档。
