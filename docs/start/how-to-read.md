# 怎么读这份导航

这一页把读法说清楚。后面每一课都应该能在这一页里读完，不用一边读一边去仓库里找文件。

## 你现在的位置

你是前端，准备看懂一个用 TypeScript 写的 AI 客户端。Cherry Studio 很大，消息列表、主进程、模型调用、编码助手的适配器叠在一起。如果每课只丢一个路径，阅读会不停被打断，主线也接不起来。

所以这门课的约定是：

- 问题写在课里。比如「字为什么是一个一个冒出来的」。
- 回答这个问题需要的代码，摘在课里，并在代码下面解释这几行在干什么。
- 仓库路径放在每课最后。那是你以后想对着行号深挖时用的，不是这一坐的作业。

一条主线贯穿全部课程：你在输入框里问「今天北京天气怎么样」，这句话怎样离开 React，怎样进到模型，模型如果要搜网页，结果又怎样回到气泡里。

## 阅读顺序

按侧边栏从上到下。前半段是你已经会的界面，中间是 Electron 把网页和 Node 隔开的那条边界，后半段才是模型、工具循环和 agent。每一课结尾都指向下一课，顺着走就行。

遇到想深挖的点，停在那一课的路径上，打开对应文件。不用为了读完这一门课把 `src/main/ai` 一千多个文件翻一遍。
