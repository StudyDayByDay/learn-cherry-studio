# 01 怎么读

> 每一课只加一件事。先读课里的短代码，再看它在 Cherry Studio 里叫什么。

上一版读起来像注释：贴一段生产代码，再请你去打开文件。那样读不完，因为生产代码里有类型参数、注册表和边界情况，主线被名字挡住了。

这门课换成和「从零搭一个 agent」一样的读法：

1. 先遇到一个具体的麻烦。
2. 用十几行代码把麻烦解决掉。这十几行是为了教学写的，能从上读到下。
3. 最后用一小段话对上 Cherry Studio 的真名。想看生产实现时，课末有路径。

你不需要把 `src/main/ai` 翻开才能进入下一课。
